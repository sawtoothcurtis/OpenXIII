# Content reference

All the names a mod can use: [names/](names/README.md).

Generated by `oxiii mods-reference <game folder> docs/modding` (oxiii built with `--features mods`)
from the original game's files.

Textures, meshes and other objects are named `Package.Group.Name`. A mod can name any of
them in a value (for example a `Mesh` or `StaticMesh` property, or a decoration added with
`[[map.<Map>.add]]`): its package is loaded when needed (expert/content-and-network.md).
