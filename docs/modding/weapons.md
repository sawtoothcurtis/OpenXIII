# Weapon and ammo reference

All the names a mod can use: [names/](names/README.md).

Generated by `oxiii mods-reference <game folder> docs/modding` (oxiii built with `--features mods`)
from the original game's scripts: the values are the ones the game loads, without mods. Use these
class and property names in `[class."Package.Class"]` tables (see [README.md](README.md)).

Under each class, only the values it sets itself are listed; the others come from its parent
class. The base class tables list every weapon or ammo property with its type.

**Rate of fire.** The player's rate of fire is not a property: in the `NormalFire` state of
`XIIIWeapon`, the next shot is allowed when the first-person firing animation ends
(`AnimEnd`), and `PlayFiring` plays it at rate 1.0. A mod changes it with `FireAnimRate`
(and the reload and select times with `ReloadAnimRate` and `SelectAnimRate`), see
[expert/weapons.md](expert/weapons.md#weapon-animation-speeds). `ShotTime` is only used by the AI controllers.

Contents: [Weapon base classes](#weapon-base-classes), [Weapons](#weapons), [Ammo base classes](#ammo-base-classes), [Ammo](#ammo).
