# Map reference

All the names a mod can use: [names/](names/README.md).

Generated by `oxiii mods-reference <game folder> docs/modding` (oxiii built with `--features mods`)
from the game's own maps. Use these map names (the file names without `.unr`) in
`[map.<Map>…]` tables, and the checkpoint numbers in `from_checkpoint` and
`[map.<Map>.checkpoint.<N>.start]` (see [expert/maps-and-checkpoints.md](expert/maps-and-checkpoints.md)).

64 maps: 34 solo maps in the order of the story, 26 multiplayer maps, 4 technical maps.

**Checkpoints.** A save point (`XIIISaveGameTrigger`) saves the game when the player touches it,
or when the map is entered for the one the map's start triggers. Each save adds one to the
level's checkpoint number (`XIIIGameInfo.CheckpointNumber`): the map entry's save is 1, the
checkpoints reached in the map are 2, 3… in the order the player reaches them. The numbers
below follow the save points' descriptions, which the level designers numbered in the order
they are reached ("Winslow Bank 1", "Winslow Bank 2"). Loading a checkpoint loads the map
again and starts the player at the save point's teleporter.

Contents: [Solo maps](#solo-maps), [Multiplayer maps](#multiplayer-maps), [Technical maps](#technical-maps).
