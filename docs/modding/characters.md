# Character reference

All the names a mod can use: [names/](names/README.md).

Generated by `oxiii mods-reference <game folder> docs/modding` (oxiii built with `--features mods`)
from the original game's scripts: the values are the ones the game loads, without mods. Use these
class and property names in `[class."Package.Class"]` tables (see [README.md](README.md)).

The base class tables list the character properties with their type and their default in
that class. Under each character class, only the values it sets itself are listed; the
others come from its parent class. Multiplayer classes (package XIIIMP) are left out.

Characters placed in a map often carry their own values, saved by the level designer: use
`apply_to_placed = true` or a `[map.<Map>.class."..."]` table to change them (see
[expert/characters.md](expert/characters.md#changing-characters)). Enemies created during play by a generator
(`XIDPawn.GenNMI` and others, last section) take several of their settings from the
generator placed in the map.

Contents: [Character base classes](#character-base-classes), [Characters](#characters), [AI states](#ai-states), [Enemy generators](#enemy-generators).

## Characters

A class name says what a character does (its AI, its stats), not what it looks like: the look
is the `Mesh` (an animated model of [content/xiiipersos.md](content/xiiipersos.md), listed
with the characters who wear it in the maps in [character-models.md](character-models.md)).
Several classes show **XIII's own model** by default: the level designer gives their
characters in the maps another `Mesh` (those that keep it are XIII himself in cutscenes), so
a character a mod makes from one of them looks like XIII unless the mod gives it a `Mesh`
(the log warns about it).

## Enemy generators

Subclasses of `XIDPawn.GenFRD`, placed in the maps: the generators (`gennmi` and its
subclasses) create enemies during play, the other ones are actors the AI uses (patrols,
alerts, targets). These are their own settings.
